# Phone ToDo

专为 **小米 13 Ultra（HyperOS）** 打造的极简、强提醒原生 Android 待办软件，并与 Windows 透明桌面待办 `DeskTodo` 通过 GitHub 私有仓库实时双向同步。

## 核心特性

- **克制、高辨识度的精密表盘与纸单视觉**：矿石纸白 / 曜石暗色 / 纯黑 OLED 三套主题，顶部表盘式今日数据条（等宽数字显示今日解锁次数、亮屏时长、待完成数），「往日遗留」与「今日」两段式纸单布局，悬浮胶囊底栏。
- **丝滑的同窗口编辑体验**：新建待办默认开启定时提醒（无需开关），双模精密滚轮支持近 90 天快选与「年月日」展开远期选择；点击外部、下拉或返回自动保存，点击编辑区空白或标签自动收起键盘且弹窗全程零跳动；完成或删除提供 3.5 秒无损「撤销」胶囊。
- **重复待办「完成本次」**：勾选重复待办（每天/每周/每月/每年）自动完成当前周期并顺延至下一次提醒，列表、通知栏与锁屏强提醒保持一致；编辑页支持「结束重复」彻底完结。
- **准点必达与锁屏强提醒**：`AlarmManager.setAlarmClock()` 调度 + 锁屏亮屏响铃强提醒（适配 Android 14+ 全屏意图权限检测，支持物理音量键静音，设置内置「15 秒后触发锁屏强提醒」真机演练）+ 点通知直达对应待办。
- **极简解锁统计悬浮胶囊**：无常驻通知栏卡片；后台静默监听解锁并结合系统 `UsageStatsManager` 校准兜底，解锁后在顶部弹出轻量黑曜石胶囊，仅展示「今日第 N 次打开 | 已用时长」，点击直达 24 小时节律与 App 时长统计页。
- **GitHub 私有仓库双向同步**：与 Windows `DeskTodo` 共用私有仓库内的 `sync-data.json`（强制校验 `private: true` 防误传公开库，并发编辑自动再合并防丢数据，条目级 LWW + 30 天墓碑自动清理）。
- **通用格式导入与导出**：设置内支持标准 JSON、CSV、Markdown / 纯文本清单的导入与导出，同时静默兼容第三方 JSON 任务备份；本地 `data.json` 损坏时自动从最近有效滚动备份恢复。
- **应用内在线更新**：内置 GitHub Releases 自动检查、进度下载与覆盖安装（固定发布证书签名，升级不丢数据）。

## 一、首次安装小米 13 Ultra（HyperOS）保活清单

打开 **Phone ToDo → 右上角设置 → 小米 13 Ultra 保活与权限**：

1. 确认开启 **「静默后台解锁监听」**（无通知栏常驻卡片）
2. 依次开启：**通知权限**、**精准闹钟权限**、**显示悬浮窗**（顶部解锁胶囊必备）、**使用情况访问权限**、**省电策略：无限制**、**锁屏强提醒（全屏通知）**
3. 小米专属两项（系统私有项无法自动检测，按提示勾选即可生效）：
   - **小米自启动**：开启
   - **小米后台弹出界面 & 锁屏显示**：在「其他权限」中勾选
4. 点击 **「立即预览顶部胶囊」** 验证悬浮窗效果，并用 **「15 秒后触发锁屏强提醒」** 锁屏实测闹钟唤醒！

> 注意：如果你此前安装过 `app-debug.apk` 测试版，首次安装 GitHub Release 的正式签名 APK 前请先卸载旧测试版；之后所有 GitHub Release 均使用同一发布密钥签名，直接在 **设置 → 应用更新** 一键覆盖升级即可。

## 二、GitHub 私有仓库双向同步（与 DeskTodo 互通）

1. 在 GitHub 创建一个 **Private（私有）** 仓库（例如 `你的用户名/todo-sync`）
2. 生成一个 Fine-grained Personal Access Token，仅授权该仓库的 **Contents: Read and write** 与 **Metadata: Read-only**
3. 在手机端 **设置 → GitHub 私有仓库同步** 与电脑端 DeskTodo 设置中填入同一个仓库名与 Token，点 **「验证并启用同步」** 即可（软件会自动拦截非私有仓库，防止个人数据泄露）

---

## 三、应用内更新（GitHub Releases）

1. 打开 **Phone ToDo → 设置 → 应用更新（GitHub Releases）**
2. 默认监听仓库：`haaharden/phone-todo`
3. 点 **「检查更新」**，有新版时点击 **「下载并更新」** 即可下载 APK 并拉起系统安装器

---

## 四、本地编译与检查

cd phone-todo
.\gradlew.bat testDebugUnitTest lintDebug assembleRelease
